同步行为

高级设置

设置后书签文件上传前会用 AES-256 加密，云端只存密文。密钥仅保存在本地，忘记密钥无法恢复加密数据。

多设备注意：所有设备必须使用完全相同的加密密钥，否则无法解密对方同步的书签文件，导致同步失败。更换设备时请确保密钥一致。

当本次同步要删除的书签超过此比例时，自动中止同步，防止数据丢失。默认 50%。

选择界面显示模式，"跟随系统"会自动检测系统深色模式设置。

每台设备唯一标识，用于多设备同步时识别变更来源。重装扩展会生成新 ID。

首次保存会自动检测本地和云端书签状态并完成首次同步；之后保存仅更新配置。

配置管理

导出配置用于备份或迁移到其他设备。导出文件包含服务器地址、用户名、密码等敏感信息，请妥善保管。

书签管理

本地书签的导入导出工具，仅操作本地书签，与云端同步无关。

导出/导入支持选择性勾选；一键清空前会自动备份，防止误操作。

备份管理

同步前自动备份本地书签，保留最近 5 份。覆盖式导入前也会自动备份。可从备份恢复。

隐私政策

本扩展不收集任何数据，不连接任何第三方服务器，您的书签数据完全由您自己掌控。

查看完整隐私政策

一、我们是谁

极客云签 (GeekMark) 是一款开源的浏览器书签同步扩展，帮助用户通过 WebDAV 协议在多设备间同步浏览器书签。本扩展由开发者独立维护，不隶属于任何公司或组织。

二、我们收集哪些数据

我们不收集任何用户数据。

本扩展不会：

  • 收集您的书签内容
  • 收集您的浏览历史
  • 收集您的个人信息
  • 收集您的设备信息
  • 向任何第三方服务器发送数据
  • 使用任何分析或统计工具
  • 显示任何广告

三、您的数据存储在哪里

您的所有数据仅存储在以下两个位置：

  1. 您的本地设备：通过浏览器的 chrome.storage API 存储配置信息（WebDAV 地址、用户名、密码、同步设置等），这些数据仅保存在您的设备上。
  2. 您自己的 WebDAV 服务器：书签数据通过 WebDAV 协议直接上传到您自己配置的 WebDAV 服务器（如 123 云盘、坚果云等），我们不拥有、不访问、不存储这些数据。

我们没有任何服务器，也没有任何云端数据库。

四、数据如何传输

  • 本扩展直接与您配置的 WebDAV 服务器通信，不经过任何中间服务器。
  • 传输过程使用 HTTPS 加密（取决于您的 WebDAV 服务器是否支持）。
  • 如果您启用了端到端加密功能，书签数据在上传前会在您的本地设备上使用 AES-256-GCM 算法加密，即使 WebDAV 服务器被攻破，攻击者也无法读取您的书签内容。
  • 加密密钥仅保存在您的本地设备上，不会上传到任何地方。

五、权限说明

权限 用途
bookmarks 读取和修改浏览器书签，这是本扩展的核心功能
storage 在您的本地设备上保存配置信息和同步状态
alarms 实现定时同步功能
notifications 在同步成功或失败时向您发送桌面通知
host_permissions 允许扩展访问您配置的任意 WebDAV 服务器地址。本扩展仅访问您明确配置的 WebDAV 服务器，不会访问其他网站

六、数据删除

您可以随时：

  • 在扩展设置中清除配置数据
  • 在 WebDAV 服务器上删除书签文件和变更日志文件
  • 卸载扩展，所有本地数据将被浏览器自动清除

七、变更日志

本扩展会在您的 WebDAV 服务器上创建一个 changes.json 文件，用于记录书签的增删改操作时间戳，实现多设备智能同步。该文件仅包含书签的 URL、标题、操作类型和时间戳，不包含任何个人信息。您可以随时删除该文件，不影响书签数据本身。

八、联系我们

如果您对本隐私政策有任何疑问，可以通过 GitHub 项目仓库提交 Issue。

总结：本扩展不收集任何数据，不连接任何第三方服务器，您的书签数据完全由您自己掌控。
